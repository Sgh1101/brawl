# Brawl Arena 3v3

브라우저에서 바로 하는 탑뷰 3대3 슈팅 게임. 장르(탑뷰 3v3)만 참고했고 이름·캐릭터·그림·소리는 전부 오리지널이야.

## 플레이
- PC: WASD 이동, 마우스 조준, 클릭 공격, E 슈퍼
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 조이스틱 조준 후 떼면 발사(짧게 탭하면 자동 조준), 노란 버튼 슈퍼

## 지금 들어간 것 (1단계)
- 젬 그랩: 젬 10개 이상 모아 15초 버티면 승리, 한 판 2분 30초
- 캐릭터 3명: Bolder(탱커, 산탄 + 돌진), Vexa(원거리, 관통 연사), Pogo(투척, 벽 너머 폭탄 + 벽 부수기)
- 탄 3칸 충전, 맞히면 차는 슈퍼, 수풀 숨기, 부서지는 벽, 봇 5명
- 홈 화면, 결과 화면, 트로피(로컬 저장)

## 실행
빌드 없음. 정적 서버로 열면 돼: `npx serve .`

## 구조
- `src/core` 공용(Vec, Storage) · `src/data` 캐릭터/맵 데이터 · `src/game` 매치·전투·봇
- `src/modes` 모드(Modes 레지스트리에 추가) · `src/ui` 렌더링·입력·HUD · `src/screens` 홈/결과 등 화면
